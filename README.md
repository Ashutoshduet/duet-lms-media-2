# duet-lms-media-2
DUET STEM Lab LMS lesson videos, part 2 (duetpower.in/lms).
The first media site (duet-lms-media) is at the 1 GB GitHub Pages limit, so newer lessons are served from here.

- `<lesson-id>.mp4` – narrated Hindi teacher video for the lesson
- `walkthrough/<lesson-id>.mp4` + `.jpg` – model walkthrough of the DUET lab models used in the lesson

Plant Kingdom (pk-*) and Animal Kingdom (ak-*) courses, added October 2026.
